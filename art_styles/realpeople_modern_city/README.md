# 真人现代都市风格

真实质感的都市风格，适合现代题材漫剧。

## 风格特点

- **真实质感**：接近真人演员的视觉效果
- **都市氛围**：现代城市背景和生活场景
- **自然光影**：真实的光照和阴影
- **生活化**：日常生活的真实呈现

## 适用题材

- 现代都市
- 职场故事
- 爱情题材
- 社会现实

## 提示词模板

### 角色生成

```
真人质感，现代都市风格，realistic human character，
[角色特征]，[服装描述]，
natural lighting，
urban background，
portrait photography style，
图中不要有任何文字
```

### 场景生成

```
真人质感场景，现代都市，realistic urban environment，
[场景描述]，[时间描述]，
natural lighting，
depth of field，
street photography style，
图中不要有任何文字
```

## 注意事项

1. **保持真实**：不要过度美化或卡通化
2. **光影自然**：使用真实的光照效果
3. **细节丰富**：展现都市生活的细节
4. **氛围营造**：通过光影和构图营造氛围
