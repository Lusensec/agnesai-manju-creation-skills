# 2D 扁平设计风格

简约干净的扁平化设计，适合现代都市题材。

## 风格特点

- **简约线条**：干净的轮廓， minimal 装饰
- **明快色彩**：高饱和度，对比鲜明
- **几何化**：人物和场景简化为几何形状
- **现代感**：符合当代审美

## 适用题材

- 现代都市
- 职场故事
- 青春校园
- 科幻题材

## 提示词模板


## 色彩体系

| 类型 | 颜色 |
|------|------|
| 主色 | 蓝色系、绿色系 |
| 辅助色 | 黄色、橙色 |
| 点缀色 | 红色、紫色 |
| 背景色 | 白色、浅灰 |

## 注意事项

1. **保持简约**：避免过多细节
2. **色彩鲜明**：使用高饱和度色彩
3. **几何化**：人物和场景简化为几何形状
4. **无阴影**：不使用阴影和渐变
