# 2D 国风风格

国风二次元风格，融合中国传统美学与现代动漫技法。

## 风格特点

- **水墨意境**：淡雅的色彩，留白的构图
- **飘逸灵动**：流畅的线条，动态的表现
- **传统元素**：汉服、山水、花鸟等元素
- **现代审美**：日式动画渲染，赛璐璐平涂

## 适用题材

- 古装剧
- 仙侠题材
- 历史题材
- 武侠题材

## 色彩体系

| 颜色 | 值 | 用途 |
|------|-----|------|
| 月白 | #E6F2FF | 背景、天空 |
| 墨黑 | #1A1A1A | 头发、墨线 |
| 青绿 | #4A7C59 | 山水、植物 |
| 赭石 | #8B4513 | 木质、土地 |
| 朱砂 | #C41E3A | 点缀、装饰 |

## 注意事项

1. **禁止写实**：不要使用照片级写实风格
2. **禁止 3D**：不要使用 3D 渲染效果
3. **禁止赛博朋克**：不要使用科幻元素
4. **保持统一**：同一项目的风格应保持一致

## 衍生风格

- 日景 → 夜景（调整光照）
- 春季 → 冬季（调整植被）
- 白天 → 黄昏（调整色调）
