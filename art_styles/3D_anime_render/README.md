# 3D 动漫渲染风格

立体渲染的动漫风格，兼具 3D 质感和动漫美感。

## 风格特点

- **立体渲染**：具有深度和层次感的 3D 效果
- **动漫质感**：保留动漫的角色设计和表情
- **光影丰富**：精细的光影处理
- **材质细腻**：服装、头发的细节表现

## 适用题材

- 动漫风奇幻
- 游戏改编
- 特效-heavy 场景
- 动作场面

## 提示词模板

### 角色生成

```
3D 动漫渲染，stylized 3D character，
anime-inspired 3D model，
[角色特征]，[服装描述]，
subsurface scattering，
cinematic lighting，
3/4 视角，动态姿势，
图中不要有任何文字
```

### 场景生成

```
3D 动漫渲染场景，stylized 3D environment，
anime-inspired 3D background，
[场景描述]，[氛围描述]，
volumetric lighting，
depth of field，
图中不要有任何文字
```

## 注意事项

1. **保持动漫感**：不要过于写实
2. **光影合理**：使用戏剧化光照
3. **细节适度**：保留关键细节，避免过度复杂
4. **风格统一**：同一项目保持相同渲染风格
